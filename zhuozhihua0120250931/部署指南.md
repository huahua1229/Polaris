# Polaris 小站・部署指南（GitHub Pages + Supabase 云数据库）

本指南帮你把网站从 "只能本机打开" 升级为 "任何人都能访问"，并且**留言、内容管理、作者口令全部真正生效在云端**—— 别人访问时能看到你维护的内容，也能留言。

> 全程免费。预计 30~60 分钟，只需按顺序照做。



***

## 一、你需要注册两个账号



| 平台                                             | 用途                   | 注册方式                 |
| ---------------------------------------------- | -------------------- | -------------------- |
| GitHub（[github.com](https://github.com)）       | 托管网页（免费）             | 邮箱注册                 |
| Supabase（[supabase.com](https://supabase.com)） | 云数据库 + 服务端函数（免费额度足够） | 邮箱注册（可用 GitHub 账号登录） |



***

## 二、搭建云端数据库（Supabase，约 10 分钟）



1. 登录 [supabase.com](https://supabase.com) → **New project** 创建一个项目（区域建议选离你近的，如 Singapore/ap-southeast-1）

2. 创建后进入项目，左侧菜单找到 **SQL Editor**（SQL 编辑器）

3. 把本目录下 `_supabase/schema.sql` 的全部内容粘贴进去，点 **Run**

* 这一步会创建 3 张表（站点内容 / 留言 / 作者口令）并设置好权限：


  * 所有人可以看内容、看留言、发留言

  * **只有你的服务端函数能改内容、改口令、删留言**（前端和普通访客都改不了）

### 部署服务端函数（Edge Function）



1. 左侧菜单进入 **Edge Functions**

2. 点 **Create a new function**，函数名填：`polaris-api`

3. 在编辑器里粘贴本目录 `_supabase/functions/polaris-api/index.ts` 的全部内容，点 **Deploy** 部署

4. 部署后进入该函数的 **Secrets（密钥）** 设置，添加：

* 名称：`SUPABASE_SERVICE_ROLE_KEY`

* 值：在 **Project Settings → API** 页面里复制 `service_role` 那一行的 key

* （`SUPABASE_URL` 系统会自动注入，不用管）

1. 记下函数的访问地址：**https:// 你的项目 ref.functions.supabase.co/polaris-api**

* 项目 ref 在项目设置里能看到（形如 `abcdefghijk` 的小写字母串）



***

## 三、把云端地址填进网站（2 分钟）

打开网站目录下的 `static/polaris-cloud.js`，把顶部这一行改成你的函数地址：



```
window.POLARIS\_CLOUD\_CONFIG = {

&#x20;   fnUrl: ''   // ← 改成 https://你的项目ref.functions.supabase.co/polaris-api

};
```

> 不填（保持 
>
> `''`
>
> ）时网站自动退回 "本地模式"（数据只存浏览器，适合本机试用）；填好后所有数据走云端。



***

## 四、发布到 GitHub Pages（约 10 分钟）

### 方式 A：命令行（推荐，需电脑装有 git）

在网站目录（`zhuozhihua0120250931`）里打开终端，依次执行：



```
git init

git add .

git commit -m "Polaris 小站"

git branch -M main

git remote add origin https://github.com/你的用户名/你的仓库名.git

git push -u origin main
```

> 若没装 git，或不会用命令行，直接用方式 B。

### 方式 B：网页上传（无需装任何软件）



1. GitHub 上 **New repository** 建一个仓库（名字随意，如 `polaris-site`，选 Public）

2. 进入仓库 → **Add file → Upload files** → 把整个文件夹的内容拖进去上传

* **注意**：要把 `index.html`、`static/` 文件夹、`_supabase/` 文件夹等全部上传，保持目录结构不变

1. 仓库 **Settings → Pages** → Source 选 **Deploy from a branch** → Branch 选 `main` → Save

### 等待并访问



* 开启 Pages 后等 1\~3 分钟，页面显示 **Your site is live at** 就是成功了

* 你的网址是：`https://你的用户名.github.io/你的仓库名/`

* 把这个网址发给任何人，对方都能打开你的网站、看到留言

## 六、日常使用说明



| 操作               | 谁可以 | 说明                         |
| ---------------- | --- | -------------------------- |
| 浏览网站             | 所有人 | 直接打开网址                     |
| 发留言 / 回复 / 点赞    | 所有人 | 无需登录，实时同步到云端               |
| 修改内容 / 改口令 / 删留言 | 仅作者 | 管理面板需口令验证，口令校验在服务器完成，前端拿不到 |
| 数据备份             | 作者  | 管理面板「数据」页签可导出 JSON、导入恢复    |

**安全说明**：口令以 PBKDF2 加盐哈希存储在云端数据库，只有服务端函数能读取；前端不保存明文口令（仅在本次会话内临时使用）。数据库行级权限已配置：普通访客无法直接改数据。

## 七、常见问题



* **打不开线上网址？** 检查是否已推送到 GitHub 且 Pages 已启用；首次部署后等几分钟

* **国内访问 GitHub Pages 偶尔慢？** 属正常现象（服务器在境外）；追求稳定可后续升级云服务器方案

* **本地打开（file://）还能用吗？** 能。`fnUrl` 已填写时本地打开同样走云端；未填写时自动用本地存储

* **想改口令忘了？** 在 Supabase SQL Editor 执行 `delete from admin_auth;` 后再执行一次 `schema.sql` 中最后一条 INSERT 即可重置为默认口令

* **删除了云端内容想找回？** 用管理面板导出的 JSON 备份导入恢复
